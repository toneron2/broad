### Page 3: Implementation Details

**Phase 0: Rule-Based Reasoning (2-3 months)**

```python
# Simple rule-based access control

def check_access(resource, context):
    if resource.power_intensive and context.battery < 20:
        return DENIED("Battery too low")

    if not context.permissions.has(resource.type):
        return DENIED("Missing permission")

    if context.privacy_mode and resource.data_sensitive:
        return DENIED("Privacy mode active")

    return GRANTED
```

**Performance:** <5ms per decision
**Purpose:** Prove architecture works

**Phase 1: Logic Engine (6-9 months)**

# Multi-paradigm reasoning

from logic_engine import Temporal, Deontic, Fuzzy, Modal

## Design Guidelines for All Materials

### Typography
- **Headers:** Bold, clear, sans-serif (e.g., Inter, Open Sans)
- **Body:** Readable, 11-12pt minimum
- **Code:** Monospace (e.g., Fira Code, JetBrains Mono)
- **Emphasis:** Use color, not just bold/italic

### Iconography
- **Trust:** Shields, locks, checkmarks
- **Accessibility:** People icons, hands, simple gestures
- **Technology:** Minimal circuit patterns, flowing connections (not rigid boxes)
- **Community:** Network nodes, hands together, shared resources

### Visual Style
- **Flowing, not rigid:** Use curves, rivers, organic shapes (inspired by sketch.jpg)
- **Approachable, not corporate:** Warm colors, human-centered imagery
- **Clear hierarchy:** Important info visually prominent
- **Whitespace:** Don't cram - let content breathe

### Photography/Illustration
- **Real people:** Show target users (farmers, health workers, students)
- **Authentic contexts:** Rural clinics, fields, community centers (not stock photo offices)
- **Diverse representation:** Global South, different ages/abilities
- **Action-oriented:** People USING technology, not just posing

### Dos and Don'ts

**DO:**
✅ Show real use cases with human stories
✅ Use simple language (no unnecessary jargon)
✅ Emphasize trust, privacy, accessibility
✅ Make architecture flow visual (not boxes and arrows)
✅ Include "honest unknowns" (builds credibility)

**DON'T:**
❌ Use corporate stock photos
❌ Make it look like surveillance tech
❌ Overpromise ("AI will solve everything")
❌ Hide limitations or challenges
❌ Use aggressive/cold colors (reds, grays)
