## Troubleshooting Future Pushes

### If Push is Rejected
Usually means remote has changes you don't have locally:
```bash
git pull --rebase
git push
```

### If You Need to Work from Another Computer
Clone the repository:
```bash
git clone https://github.com/toneron2/esn.git
cd esn
```

### If You Accidentally Delete Local Folder
No problem! Just clone again:
```bash
cd ~/Desktop

```
