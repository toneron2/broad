# Publication Metadata

Records of published videos with YouTube IDs, URLs, and performance metrics.

## Structure

```
published/
└── {video-name}-metadata.md
```

## Created By

`youtube-publisher` agent via `/produce-content` command.

## Contents

Each metadata file tracks:
- YouTube video ID and URL
- Publication date/status
- Title, description, tags
- Source material references
- Performance metrics (updated periodically)
